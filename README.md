# STARFIRE 2 backup repo
## Note: A few countries have more than 5000 Tx. However, FMList only allows access to 5000 Tx per country. Hence these countries shall be called '5k countries' for ease of communication.
### Project/Stat_model_STARFIRE.ipynb : Correlation studies between pop dens and number of Tx.
### Project/Pixel_method.ipynb : Trying different models for 5k countries to account for missing Tx info.
### Project/AUS_validate.ipynb : Validating probabilistic method for Tx location
### Project/starfire_main.ipynb : STARFIRE pipeline
### Project/GEOTiff_averagetrial.ipynb : Algorithm to convert GEOTIFF into HEALPix format.
### Project/Country_Corr.ipynb : Check individual countries for correlations.
### Project/PRATUSH_RFIcurve.ipynb : Code to obtain ground track for different satellite orbits and thus HEALPix pixels.
